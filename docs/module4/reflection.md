# Module 4 AI Tool Reflection

## GitHub Copilot

I used Copilot while turning the local project folder into a Git repository and
connecting it to GitHub. It helped with the Git initialization, branch, remote,
staging, commit, and push workflow. When the push failed, the useful part of the
workflow was separating an authentication problem from a problem in the project
itself and changing the remote from SSH to HTTPS. Based on this work, Copilot
fit a focused repository-setup and command-troubleshooting task.

## Cursor

I did not use Cursor during this project, so I cannot honestly evaluate its
results or compare its performance from personal evidence. I would need to use
it on the same kind of coding or repository task before deciding where its
workflow fits best. Leaving this limitation visible is more accurate than
claiming experience I did not have.

## Claude Code

I installed Claude Code and completed its first-time setup inside the Task
Tracker repository. The `/status` command confirmed the installed version, the
authenticated Team session, and the correct working directory. This terminal
workflow fit environment and repository-context verification because the
evidence came directly from the tool running at the project root. I did not use
Claude Code to change the application, so I am not claiming implementation
results from it.

## Workflow comparison

I do not consider one tool the overall winner. In the work I actually
performed, Copilot fit the Git setup and authentication-troubleshooting task,
while Claude Code fit command-line setup and repository-context verification.
Cursor was not used, so it remains unevaluated rather than being ranked above or
below the other tools. The appropriate workflow depends on the engineering task
and should be judged from observed results rather than the tool name alone.
